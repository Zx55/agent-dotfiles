# Presentation storyboard

## Talk brief

- Audience and assumed knowledge
- Target speaking time and language
- Main message and intended takeaway
- Authoritative materials and unresolved factual questions
- Theme and visual conventions

## Slide plan

For each approved page, record the following fields. Add only as many pages as the narrative requires.

- Number and working title
- One sentence the audience should retain
- Content and evidence
- Layout and visual assets
- Relationship to neighboring pages, including any fixed visual anchors
- Approximate speaking time
- Source files or links and open questions
- Status of layout, HTML, notes, and visual review

## Timing and review

Track total estimated time, rehearsal observations, and remaining content decisions here. Full scripts belong in `notes/slideNN.md`.
